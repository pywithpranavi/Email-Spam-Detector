This Machine Learning project classifies emails or messages as Spam or Not Spam using Natural Language Processing (NLP) techniques and classification algorithms.
This project detects spam emails/messages using Machine Learning and NLP techniques.

 Features
Text preprocessing
Tokenization
TF-IDF vectorization
Spam classification
Accuracy evaluation
